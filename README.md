## 📖 主题简介

**启灵 (QiLing)** 是一款专为站长、企业、独立开发者及数字化服务商量身打造的**现代化、高复用、高性能模块化 WordPress 企业级主题**。

主题彻底摒弃了传统建站依赖 Elementor 等第三方重型可视化插件导致的臃肿代码与缓慢加载弊端，**从底层构建了一套极简、原生、轻量级的高性能积木式模块化渲染引擎**。无论是构建科技公司品牌站、外贸独立站、工业制造官网、医疗门诊、律所咨询，还是电竞赛事、生活服务、个人作品集与数字商业平台，启灵都能提供极致顺滑、自由灵活且开箱即用的建站体验。

## 🌟 核心功能与亮点

### 1. 🧩 80+ 原生专业级业务功能模块（积木式极速拼装）
- **无臃肿依赖**：基于原生 WordPress 机制开发，无需安装任何额外的大型第三方页面构建器插件，页面毫秒级秒开。
- **自由拖拽与排版**：支持模块上下拖拽排序、实时显示/隐藏开关、模块复制与独立配置。
- **全方位视觉定制**：每个模块均支持内边距（Padding）、背景模式（纯色 / 多彩渐变 / 视差背景图片 / 动态视频）、文字排版与动效设置。
- **滚动视差动画（Scroll Reveal）**：全页模块原生支持流光溢彩的平滑交错入场视差动画，带来媲美顶级 SaaS 官网的动效质感。

### 2. 🎨 108+ 官方行业专属开箱即用模板包（一键装配）
- **全行业覆盖**：内置 108+ 款涵盖科技制造、医疗门诊、律师事务所、外贸跨境、新能源、教育培训、电竞赛事/酒店/俱乐部、文旅酒店、餐饮加盟、个人简历等全品类官方 JSON 页面数据包。
- **一键套用与自愈机制**：创建页面选择对应行业模板，一键载入全套精心调校的色彩规范、专业文案、高精配图与模块预设，立即可见完整商业站点。
- **装修防覆盖安全机制**：智能区分“模板外壳切换”与“全新装修应用”，并自动留存历史装修备份，防止误操作丢失站长辛苦编辑的内容。

### 3. ⚡ 极致性能与深度搜索引擎优化（SEO Ready）
- **轻量纯净底层**：CSS 与 JS 资源均经过极致压缩与异步按需加载，静态无冗余，PageSpeed 跑分极高。
- **原生 TDK 智能提取**：支持针对首页、独立页面、分类目录与文章详情页自定义 SEO 标题、关键词与描述。

## 🚀 快速上手与运行环境

### 运行环境推荐
- **WordPress 核心版本**：WordPress 5.8 及以上（推荐 WordPress 6.0 ~ 6.9+ 最新稳定版）
- **PHP 版本**：PHP 8.1 / PHP 8.2 / PHP 8.3
- **数据库**：MySQL 5.7 及以上，或 MariaDB 10.3 及以上
- **Web 服务器**：Nginx / Apache / LiteSpeed（推荐使用伪静态开启固定链接）

### 安装步骤
1. **下载或克隆主题代码包**：
   将本项目源码克隆或上传至 WordPress 网站的 `/wp-content/themes/qiling/` 目录中。
2. **启用主题**：
   登录 WordPress 后台，在【外观】->【主题】列表中找到 **启灵 (QiLing)** 并点击【启用】。
3. **快速装配页面**：
   进入【页面】->【新建页面】，在右侧【页面属性】中选择您所需的行业模板（如“企业官网”、“科技外贸”、“电竞俱乐部”等），勾选**【保存时应用所选页面模板的默认装修】**后发布，即可一秒获得完整的精美行业站点！
4. **可视化自由微调**：
   在页面下方的“功能模块”管理区域，直接对文字、图片、按钮链接进行可视化修改并保存即可。
